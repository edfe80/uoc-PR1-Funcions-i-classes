# PRA1 – Funcions i classes en JavaScript

## Programació Web – UOC

### Descripció

Aquest repositori conté la resolució de la primera pràctica (PRA1) de l'assignatura Programació Web 

### Etapes de la pràctica

1. **Creació de la classe `Show`**
2. **Creació de la classe `Progress`**
3. **Creació de la classe `ShowList`**
4. **Funcions fletxa**
5. **Funció recursiva i `markEpisodeWatched`**
6. **Ús de `reduce`**
7. **Funció amb destructuring i spread**
8. **Maneig de dates**
9. **Funció avançada amb múltiples operadors**

### Execució

Per executar el projecte, cal tenir Node.js instal·lat.

Des d'un terminal, dins del directori del projecte, executar:

```bash
node pra1.js
```

Permeten comprovar el funcionament de les diferents etapes.
